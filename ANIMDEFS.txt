// THE MIRROR'S SURFACE.
//
// A camera texture: the scene rendered from a viewpoint actor straight onto a model's skin.
// That is the whole trick behind being able to look at yourself.
//
// 512 square. This renders the entire scene a second time, and in VR it is already being
// drawn twice -- so it is a tool you switch on to check something and switch off again,
// never something left running.
cameratexture RSMIRROR 512 512
	fit 512 512
